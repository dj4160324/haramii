# Third-party runtime

cp-sat-wasm 2.1.0 is a community WebAssembly build of Google OR-Tools maintained at https://github.com/Axelwickm/or-tools-wasm . It is not an official Google JavaScript distribution. Original license and package metadata are included alongside this notice. The copied runtime files are unmodified; only the haramii integration and solver model are new.

Google OR-Tools: https://github.com/google/or-tools (Apache License 2.0).
The JavaScript distribution bundles protobuf and long helpers; their available license notices are retained here. Retained source comments and license notices in runtime files are not stripped.
